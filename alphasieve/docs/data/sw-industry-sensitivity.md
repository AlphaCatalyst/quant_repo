# 申万行业口径敏感性（只读观察）

状态：已运行（只读观察）。2026-10-07 核对。

日期：2026-10-04。区间限定为 dev 2012-01-01—2022-12-31；A 目标权重实际覆盖 2016-01-04—2022-12-28，共 171 次调仓。没有运行策略、优化器、训练、模拟或评估入口；没有写 trial ledger。明细在 `/data/alphasieve/reports/sw_sensitivity/`，用 `uv run python tools/sw_industry_sensitivity.py` 重做。

## 方法与范围

- 组合：读取锁定的 v4、P1–P4、C2 的 `weights.parquet` 目标权重。C1 已 abandoned，无结果。基准一是试验实际使用的 D-31 中证 500 可投资成分流通市值代理；基准二是 DoltHub 中证 500 历史月末权重，在下一交易日起使用、以面板后复权收盘价漂移，并归一至 BaoStock 可投资成分。两种基准都只用于目标暴露，未重新计算收益、实际成交或风险。
- 行业：当前面板的 BaoStock 证监会快照、westock 2026-10-03 申万一级快照、申万历史的“生效日后首个交易日”、以及“生效日与更新日较晚者之后首个交易日”。缺分类单列 `unknown`，不重新归一已知行业。每次调仓先按行业汇总 `目标权重−基准权重`，再取最大绝对值；超过 2% 指严格大于 2% 加 1e-8 容差。
- 因子：读取 4 个已锁定或通过稳健性关卡的保存因子缓存及 dev 面板标签。逐日以行业哑变量和 `log(circ_mv)` 对因子值做最小二乘残差，求残差与原标签的 Spearman RankIC；ICIR 为日 IC 均值除以样本标准差。复现 `evaluation/metrics.py::neutralized_ic` 的公式，申万用逐日行业；仅检验 L2 `neutral_ic_mean / raw_ic_mean ≥ 0.5` 的单项敏感性。

## 结论与建议

申万一级行业会实质改变“行业 ±2%”的解释：保存 A 组合按历史生效口径重标记后，几乎每次调仓至少有一个行业超过 2%。但这不是新约束下的可行性检验，也不改变既有 A 试验全部未通过 dev 验收的结论。所选四个因子的行业中性化 L2 单项结论没有翻转；无法据此重判整套因子接受结论。

建议保留既有 `industry_source=csrc` 默认值，以维持旧 trial 身份与复现口径；在报告中明确其非 PIT 性质。新策略若需申万约束，应由人决定独立配置、预算和可得性证明后另行登记。当前 `sw1_pit` 实现使用保守更新日规则，2016–2022 仍有较大 `unknown` 权重；若不能取得真实首次发布日期，不宜把“历史生效”称为严格当时可得，也不宜直接把申万口径设为默认约束。此建议不修改任何配置或验收状态。
