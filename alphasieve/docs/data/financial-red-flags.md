# 财报排雷（2026-10-04）

入口：`uv run alphasieve redflag scan --asof 2026-10-04 --universe csi800 --json`、`redflag show <code> --asof <date>`、`redflag rules`、`redflag explain <code> [--asof <date>]`。`--codes sh.600000,sz.000001` 与 `--universe all` 也可用。`alphasieve.redflag.flags_for(settings, codes, asof)` 不写文件；扫描写入 `<hot_root>/redflag/<asof>/results.{parquet,json}`。后端计算数值和级别，agent 只解读证据，人决定是否采取行动。

## 规则和级别

九条可用规则均按本次扫描集合中的申万一级行业比较。每条规则在同业可评估样本达到 15 只时使用同业，否则使用本次扫描中所有可评估的非金融股票。同业未知也回退全集。高风险方向的中秩分位达到 90% 判琥珀，达到 97% 判红；低风险方向先反转分位。中秩分位为 `(低于该值的数量 + 同值数量/2) / 样本数`，避免大量零值同时进入尾部。因此离散值和小样本的实际命中比例可能偏离 10%/3%。每条结果给出分位 `industry_percentile`、实际使用的 `peer_group` 和 `peer_count`，以及原行业可评估数 `industry_sample`。这些分位目标是预先固定的筛查设计，**没有用历史爆雷案例拟合**。

| ID | 指标 | 风险方向 |
| --- | --- | --- |
| `receivables_growth` | 应收票据及账款同比增速－营收 TTM 同比增速 | 高 |
| `inventory_growth` | 存货同比增速－营收 TTM 同比增速 | 高 |
| `cash_profit` | 经营现金流 TTM／归母净利润 TTM；亏损期不评估 | 低 |
| `accruals` | (归母净利润 TTM－经营现金流 TTM)／总资产 | 高 |
| `goodwill` | 商誉／归母净资产 | 高 |
| `other_receivables` | 其他应收款／总资产 | 高 |
| `prepayments` | 预付款同比增速 | 高 |
| `cash_debt` | `min(短期借款／资产, 货币资金／资产)`，衡量两者同时偏高 | 高 |
| `gross_margin` | 毛利 TTM／营收 TTM | 高 |

另外仅保留两项绝对硬条件：商誉严格超过归母净资产的 50%；以及最近三个相隔一年的同季 TTM 期间，归母净利润均为正、经营现金流均为负。任一期间缺值则第二项不触发。两项的数值、期间和公告日均随结果保存。硬条件单独触发总体红，不改变同业分位。

总体红：任一硬条件，或至少两条规则红，或一条规则红且至少两条琥珀。总体琥珀：至少一条规则红或至少两条琥珀。其余为无信号；无完整报表和银行、非银金融为不可评估。单条琥珀不会升级总体。上述组合规则在本次 CSI800 扫描已达到目标区间，未根据历史案例改动。

## 时间与数据边界

westock 三张原始报表按各自 `InfoPublDate < asof` 过滤，只有三张表对同一 `EndDate` 全部可见才计算该期。非交易日 `asof` 使用最近一个已过去交易日作为有效日；公告当天不能用，最早下一个交易日可用。同比的上年报表和现金流硬条件使用同一公告过滤。比率用原始金额计算，分母非正、基期为零或字段缺失则该项不可评估；现金流和利润使用 TTM。逐规则证据含报表期、公告日、字段和同比上年字段。

数据源是 `raw/westock/financials/{lrb,zcfz,xjll}`；BaoStock 交易日历决定有效日，BaoStock 成分历史决定 CSI800。申万一级行业使用最新 westock 快照，**当前行业归属并非历史 PIT**。westock 每个报表期仅保留一个版本；历史金额可能已重述，因此公告过滤仍有残余前视风险。没有使用通达信财务包数值。`audit_opinion`、`auditor_change`、`impairment`、`capitalized_rd` 因缺少可核验历史字段列为不可用。关联交易和股权质押也没有可核验的 PIT 结构化序列。分位基于本次扫描集合；单股 `--codes` 的分位不能等同于 CSI800 扫描。级别只是同期相对异常筛查，不是欺诈结论或预测概率。
