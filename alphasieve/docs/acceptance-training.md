# 训练任务与 mandate 验收记录（2026-09-29，第二轮 2026-09-30）

对应 [18-mandates.md](18-mandates.md)、[19-training-tasks.md](19-training-tasks.md) 与 [20-training-round2.md](20-training-round2.md)。所有结果都是 dev 区间（2012–2022）上的样本外滚动结果；holdout 没有读取。第二轮结果见 §2a。

## 1. 结论

- 训练任务体系已实现并在两个 Ray 集群上实测：任务配置与校验、残差标签、滚动训练与年度内层选参、四个 mandate 的组合与回测、策略层 trial 记账、按 mandate 的搜索折扣、策略层 holdout 申请路径。
- 四个 mandate 在 dev 上都没有达到 18 的验收门槛。最接近的是 A v4（线性规划组合）：相对全收益基准年化净超额 5.3%、信息比率 1.09、跟踪误差 4.9%，但超额、最大回撤和容量三项略差于门槛。
- 两个口径问题在实测中被发现并修正，前面的结果因此作废重跑：
  - 组合收益是全收益（后复权），而中证 500 指数是价格指数，直接相比会把约 1.5%–2% 的股息率算成超额。验收改为对照全收益的成员代理；修正后 A v1 的超额从 4.0% 降到 1.5%。
  - 启发式组合构建（先填充再向基准混合、换手按比例部分移动）实际上在复制基准：A v3 平均持有 593 只，权重低于 0.4% 的有 464 只、合计 60%，跟踪误差只有 2.7%。改用线性规划后持有约 90 只，跟踪误差进入 4%–6% 的目标区间。

## 3. 各 mandate 的判断

- **A 中证 500 增强**：信号本身有效（20 日 RankIC 0.07、ICIR 0.9 以上），瓶颈在组合构建。v4 的超额有 22% 来自 2016 年，其余年份平均约 2.6%；在 20 亿规模下降到 4.3%。第二轮把 C 的事件分数和 13 个衍生因子加入后，RankIC 略升但组合 IR 全部下降，差在 2021–2022 年；A 保持 v4。A 的预算（N ≤ 9）已用完，v4 折扣后 IR 0.50。
- **C 业绩超预期漂移**：事件信号很强。全 A 2009–2022 的 60 日累计超额，最高十分组减最低十分组 6.0%，t = 20，十组单调性 0.99。但独立的事件组合持仓集中、偏小盘，成本每年约 5%，跟踪误差 16%–18%，不能单独成立。作为 A 的特征（A v5 事件）在分数层有增量（RankIC 0.056 → 0.058），在组合层没有体现。
- **B 行业 ETF 轮动**：用当前前二十大持仓建立映射后，行业特征把真实 ETF 段的 RankIC 从 0.033 提到 0.061，但组合 IR 没有提高（0.61 对照 0.78，5 年、跟踪误差 16% 下差异在噪声内）。三个版本都未通过 Sharpe 和回撤两项。持仓篮子版在两项指标上都不高于行业映射版，没有证据表明静态持仓的前视造成了虚高。
- **D 期货对冲中性**：用真实期货后，精确段对冲后为负收益，基差（年化约 −6.3%）超过了多头超额。部分对冲收益转正，但波动超过上限。D 不再作为独立 mandate 推进，降级为 A 的风险管理模块（D-32）。

## 4. 平台与记账

- 集群 1（4 个节点，每个 376 核）：A 的完整配置（8 个候选、2 个周期、3 个 seed，336 次选参拟合加 168 次重拟合）用 48 个进程约 18 分钟；因子缓存预热后约 2 分钟。
- 集群 2（2 个节点，每个 28 核）：D 用 6 个进程运行成功。
- 平台运行自动记录到 RunLab 个人空间（例如 A v1 首次运行的 run `360o8crj`、D v1 的 `r9yreipz`）。
- ledger：13 个策略层 trial（A 5、B 2、C 4、D 2），校验通过，没有未结 trial。第二轮后为 22 个（A 9、B 5、C 4、D 4），校验通过（1110 行），没有未结 trial。
- holdout 没有读取。读取流程：`train holdout-request --trial-id <id>`，再由人工 `train holdout-approve`，每个 mandate 一次。
