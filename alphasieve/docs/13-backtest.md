# 13 · 回测

回测分级进行：越往后越接近真实成交、越慢、用得越少。目的是让便宜的回测承担大部分筛选，昂贵的回测只用在少数候选上。

## 1. 分级

| 级别 | 名称 | 对象 | 方式 | 速度 | 用在 |
|---|---|---|---|---|---|
| B1 | 因子快速评估 | 单因子 | 向量化 IC / 分组收益，不模拟成交 | 秒级 | L1 |
| B2 | 因子可交易评估 | 单因子 | 多头第 5 组，带可交易性过滤与近似成本 | 秒级 | L2 |
| B3 | 组合日频模拟 | 策略（多因子 + 模型 + 组合构建） | 逐日循环，完整 A 股成交规则 | 分钟级 | 策略评估（M6）、Review Packet 附加证据 |
| B4 | 滚动样本外 | 策略 | walk-forward：每月重训、样本外拼接 | 十分钟级 | 策略晋升前 |
| B5 | Paper | 策略 | 每日用最新数据生成持仓并模拟成交，不回填 | 实时 | L5 |

B1、B2 是 agent 循环中每次评估都会跑的；B3、B4 只对通过 L4 的候选或策略跑；B5 是前瞻验证。

## 2. B1 · 因子快速评估

- 输入：因子值矩阵（日期 × 股票）、标签矩阵、股票池掩码。
- 计算：日度 RankIC、ICIR、正比例、5 分组等权收益、多空收益、换手代理。
- 不考虑成交约束与成本；标签本身已剔除买入日不可交易的样本（见 [03-data.md](03-data.md) §2.2）。
- 实现：纯 numpy / pandas 向量化，按年份分块以控制内存。

## 3. B2 · 因子可交易评估

- 每期（默认每周）选因子值最高的 20% 股票等权持有，相对股票池等权基准计算超额。
- 过滤：买入日开盘涨停、停牌的股票不能买入；卖出日开盘跌停、停牌的股票顺延卖出。
- 成本：按换手 × 单边成本（默认 0.15%）扣减。
- 输出：成本前后年化超额、超额 Sharpe、最大回撤、平均换手。
- 用于 L2 的“成本后多头超额 > 0”判断。

## 4. B3 · 组合日频模拟

### 4.1 时序约定

```text
T 日收盘后：数据更新 → 因子与模型打分 → 组合构建 → 生成目标持仓
T+1 日开盘：按开盘价（或 T+1 日 VWAP，可配置）成交
T+1 日收盘：按收盘价估值
```

### 4.2 成交规则

| 规则 | 实现 |
|---|---|
| T+1 | 当日买入的股票当日不可卖出 |
| 涨跌停 | 开盘涨停不能买入，开盘跌停不能卖出；可配置为“一字板全天不能成交” |
| 停牌 | 不能交易，持仓按停牌前收盘价估值 |
| 顺延 | 不能成交的订单顺延到下一交易日，最多 5 日，超过则取消并记录 |
| 最小单位 | 买入以 100 股为一手取整；卖出允许零股清仓 |
| 现金 | 不允许透支；先卖后买 |
| 退市 | 退市前最后交易日强制清仓，按最后成交价计 |

### 4.3 成本模型

| 成本 | 默认值 |
|---|---|
| 佣金 | 双边 0.025%，最低 5 元 |
| 印花税 | 卖出 0.05% |
| 过户费 | 双边 0.001% |
| 滑点 | 单边 0.05% |
| 冲击成本 | `k × σ × sqrt(成交额 / 当日成交额)`，k 默认 0.5（M6 起） |

成本参数写在 `config/costs.yaml`，版本化。

### 4.4 组合构建（指数增强）

- 方法：Top-K 等权，或带约束的优化（最大化预期得分 − 风险惩罚）。
- 约束：行业权重相对基准偏离 ≤ 3%；市值暴露在基准 ±0.3 标准差内；个股主动权重（相对基准权重的偏离）≤ 2%；单期换手 ≤ 30%。原先写的是个股绝对权重 ≤ 2%，但在市值加权基准下，大市值个股本身的权重就超过 2%（例如中证 800 中约 7%），绝对上限会迫使组合大幅低配这些股票，因此改为主动权重口径（D-28，2026-09-27）。
- 基准：沪深 300、中证 500、中证 1000 指数，基准收益取指数日线。

### 4.5 输出

- 净值与基准、超额净值。
- 年化收益、年化超额、跟踪误差、信息比率、最大回撤、超额最大回撤。
- 平均换手、成本占比、行业与风格暴露时间序列。
- 容量估计：按个股成交额占比约束反推的最大资金规模。
- 成交明细与未成交订单记录。

## 5. B4 · 滚动样本外

- 每月末用截至当时的数据重训模型（训练窗口默认最近 5 年），用于下一个月的打分。
- 因子选择、模型超参、组合参数都只能用当时之前的数据决定；在每个训练窗口内部完成（嵌套 walk-forward）。
- 各月样本外结果拼接成完整净值曲线。
- 在 dev 区间内做 B4 得到的是开发证据；在 holdout 区间内做 B4 需要消耗 holdout 读取预算，并只进入 Review Packet。

## 6. 敏感性检查

对通过 B3 的策略，自动跑以下变体，结果放入 Review Packet：

| 变体 | 目的 |
|---|---|
| 成本 × 2 | 成本假设是否过于乐观 |
| 延迟 1 日成交 | 信号是否依赖极短的时效 |
| 调仓频率改为每日 / 每两周 | 结果是否依赖特定频率 |
| 股票池换成相邻指数 | 是否只在特定股票池有效 |
| 去掉最好的一年 | 是否依赖单一年份 |

任一变体下超额转负，Review Packet 中高亮提示。

## 7. 引擎选择

- B1、B2：自研向量化实现，与因子评估共用代码。
- B3、B4：自研逐日循环模拟器。A 股规则固定且不复杂，自研比适配 Qlib 的 exchange 或 vectorbt 更可控，也便于写不变量测试。
- 对照：用 Qlib 回测或独立的 pandas 简版实现，对少量样本策略做交叉验证（见 [12-testing.md](12-testing.md) T5）。
- B5：与 B3 共用成交规则代码，只是时钟换成真实交易日、数据换成当日更新。

## 8. agent 能看到什么

| 回测级别 | agent 可见 |
|---|---|
| B1、B2（dev） | 全部指标 |
| B3、B4（dev） | M6 之后，策略设计循环开放时可见 |
| B3、B4（holdout） | 不可见 |
| B5 | 不可见 |
