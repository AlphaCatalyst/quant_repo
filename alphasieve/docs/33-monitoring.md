# 监控与告警 v1

## 输入与规则

`monitor run [--asof YYYY-MM-DD]` 读取本地巨潮公告、财报排雷、`theses/*.yaml`、预测台账、最新持仓快照及可选 `configs/monitor/watchlist.yaml`。默认观察名单为最新持仓代码、论点资产与配置代码的并集。公告取近 14 天的高、中重要性事件；财报排雷只对 `red`、`amber` 生成告警。预测结算日距离运行日不超过 7 天即提醒，过期且未结算升级为关注。

论点证伪条件若变量明确写为 `sina_futures_close:LH2707` 或 `stock_close:sh.600000`，且条件含 `>`、`>=`、`<` 或 `<=` 与数字阈值，使用当日或此前最新收盘价比较。其余条件每天列为“待人工核查”；数据不可用时也转人工核查并给出警告。最新持仓中论点资产权重超过该论点 `position_limit` 时生成紧急告警。这只是提示，不自动交易或结算。

## 级别、可见性与确认

级别为 `critical`（红色财报、证伪触发、超仓）、`warning`（高重要性公告、琥珀财报、预测逾期）和 `info`（中重要性公告、预测临期、人工核查）。告警 ID 由规则、对象、触发日期确定；重复运行不会重复写入。告警与确认记录均为追加式，不可改删。`monitor list [--open] [--kind KIND]` 查询；人工用户通过 `monitor ack ID --note ...` 确认。

公开观察名单和论点、预测产生的告警显示于 `/api/alerts`。仅由持仓引入的证券告警及超仓告警标记 `private`，只在 `/api/alerts/private` 显示；该接口与 `/api/book` 一样要求真人 Basic 认证，关闭网页认证时返回 403。公开告警不附带快照 ID、持仓权重或持仓来源。当前网页仅展示，确认走 CLI。

## 调度与限制

`data daily-update` 末尾自动运行监控；监控故障成为更新警告。也可由系统或人工用户单独运行 `monitor run`。v1 只投递到网页看板，不发送外部消息。公告与财报依赖本地已同步数据；市场证伪条件若无可比价格会等待人工核查。按日生成的人工核查提醒会每天新增一条，需人工确认；历史告警不会因条件消失而删除。
